# 옹벽·통로박스 스킬 테스트 도면

SiteCAD의 **열기**에서 이 폴더의 DWG를 선택한 뒤 우측 채팅창에 아래 요청을 입력합니다. 슬래시 명령은 필요 없습니다. 전체 도면을 검토하려면 먼저 **선택 해제**를 누르세요. 문자가 작으면 도면에서 확대합니다.

저장소에서는 `drawings/Test/`, 다운로드한 웹앱에서는 압축을 푼 `SiteCAD/drawings/Test/`가 이 폴더입니다. 설정에서 다른 저장 폴더를 지정했더라도 **열기**에서 이 폴더로 이동해 선택할 수 있습니다. 원본을 보존하고 기성 결과는 다른 파일명으로 저장하세요.

아래 **예상 답변**은 생성 도면의 시험 가정과 계산값으로 작성한 비교 예시입니다. 모델의 문장이 그대로 같을 필요는 없지만 수량·포함 범위·판정 근거가 일치해야 합니다. 이번에 모든 프롬프트를 LLM으로 실행한 결과를 복사한 것은 아닙니다. 표는 채팅에서 실제 표로 표시되어야 하며, 사용자가 `|`, `**` 같은 마크다운 문법을 직접 읽게 해서는 안 됩니다.

모든 도면은 **교육·회귀시험용**입니다. 구조·지반·가시설 안전계산과 시공승인을 받지 않았습니다. `normal`은 비교용 기본형이라는 뜻이며 KDS/KCS의 모든 요구사항을 만족한다는 뜻이 아닙니다.

### 1. 물량 산출·검증

기본형을 열고 다음과 같이 요청합니다.

> 이 옹벽의 콘크리트, 터파기, 일반 되메움, 구조물 뒤채움, 철근, 지수재 물량을 산출해줘. 철근 기호와 직경을 지시선으로 연결하고, 실제 가공선 길이와 배근 본수 근거를 읽어 수량표와 대조해줘. 단위중량은 제조사 공식 원문으로 독립 검증하고 결과를 채팅 표로 보여줘. 도면은 변경하지 말아줘.

**예상 답변 예시**

> 도면의 mm·모형 1:1 조건을 확인하고, 단면과 평면의 같은 구조체를 중복 합산하지 않았습니다. 철근은 기호별 가공선 실측 길이에 배근 주기의 본수를 곱했습니다. 다음은 순기하 물량이며 실제 현장 실측·손실·할증을 포함하지 않습니다.

| 항목 | 비교값 | 산출 범위 |
| --- | ---: | --- |
| 기초 콘크리트 | 5.760m³ | 2.4×0.4×6 |
| 벽체 콘크리트 | 5.400m³ | 0.3×3×6 |
| 구조체 콘크리트 합계 | 11.160m³ | 기초+벽체 |
| 린콘크리트 | 1.560m³ | 2.6×0.1×6 |
| 터파기 | 149.100m³ | 사다리꼴 단면 24.85m²×6 |
| 일반 되메움 | 4.980m³ | EL.+0.4m 아래 굴착공간에서 기초·린 제외 |
| 구조물 뒤채움 | 73.800m³ | 배면 EL.+0.4~+3.4m의 닫힌 경계×6 |
| 지수재 | 6.000m | 벽체-기초 시공이음 |
| 철근 합계 | 1,086.333kg | B1·B2·V1·H1, 순 가공길이·할증 없음 |

최종 전면 개방공간 57.600m³는 되메움이 아닙니다. 토공 균형은 **149.100=11.160+1.560+4.980+73.800+57.600**입니다. 굴착사면 1V:1H 및 양단 가시설 수직막음은 시험 설계 가정이며 일반 기준값이 아닙니다. 종방향 사면·단부 여유·토량 변화율·배수공·필터·손실·운반 물량은 포함하지 않습니다.

| 철근 기호 | 규격 | 본수 근거 | 1본 가공길이 | 총길이 | 독립 산출 중량 | 표 중량 | 대조 |
| --- | --- | --- | ---: | ---: | ---: | ---: | --- |
| B1 | D19 | 31위치×상하 2층=62본 | 2.2309m | 138.3158m | 311.211kg | 311.211kg | 일치 |
| B2 | D16 | 12위치×상하 2층=24본 | 5.8341m | 140.0184m | 218.429kg | 218.429kg | 일치 |
| V1 | D16 | 전후 2면×31위치=62본 | 3.8341m | 237.7142m | 370.834kg | 370.834kg | 일치 |
| H1 | D13 | 전후 2면×16위치=32본 | 5.8373m | 186.7936m | 185.860kg | 185.860kg | 일치 |

행 중량과 합계는 반올림 전 값으로 계산한 뒤 소수 셋째 자리로 표시합니다. 이 안내의 비교값이나 도면 표를 공식 단중 원문의 대체 근거로 사용하지 않습니다. 가공 형상·배근 투영선·기성 강조선·수량표의 같은 철근을 중복 합산하지 않아야 합니다.

> 단중 원문의 D13 0.995kg/m, D16 1.560kg/m, D19 2.250kg/m를 실제로 확인한 경우에만 위 중량을 검증 완료로 표시합니다. 답변에는 실제 읽은 공식 URL·문서명·표의 페이지와 도면 객체 근거를 붙입니다. PDF를 내려받기만 하고 표를 읽지 못했다면 “가공 길이와 본수는 확인했으나 공식 단중 원문을 판독하지 못해 중량 검증은 미완료”라고 답해야 합니다. 도면은 변경하지 않았습니다.

답변 뒤에는 “이 결과가 필요한 방식과 맞나요? 바꿀 산출·표시 규칙이 있으면 알려주세요.”처럼 개선 방법을 묻는 질문이 있어야 합니다. 사용자가 수정 방법을 알려주면 스킬 등록·수정 내용을 제안하고 승인받은 뒤 반영해야 합니다.

### 2. 설계오류 검토

오류형을 열고 다음과 같이 요청합니다.

> 이 옹벽의 설계 오류를 검토해줘. 피복, 뒤채움재·층두께·다짐도, 철근 이음 길이와 위치, 단위중량을 도면에서 읽고 KDS/KCS 원문을 MCP로 조회해 관련 기준·조항·판정 근거를 채팅 표로 보여줘. 적용 조건이 없거나 구조계산이 필요한 항목은 확인 필요로 구분하고, 도면은 수정하지 말아줘.

오류형에는 **피복 20mm, 유기질토·건설폐기물 혼합 뒤채움재, 다짐 후 층두께 400mm, 다짐도 90%, 벽체 기부의 200mm 전수 겹이음, H1 표 단중 1.200kg/m**를 의도적으로 넣었습니다. V1A/V1B 분할 가공선과 겹침 구간도 실제로 다릅니다.

모든 수치가 모든 조건에서 자동 위반이라는 뜻은 아닙니다. 검토 시 적용 기준의 종류·버전·조항과 노출·타설·다짐시험 조건을 확인해야 합니다. 정착·이음·구조 안정성 등은 도면만으로 최종 적합을 확정할 수 없습니다. 기준 원문이나 단중 원문을 읽지 못했으면 검증 완료로 처리하지 않아야 합니다.

**예상 답변 예시**

> 도면에서 아래 검토 대상을 확인했습니다. 실제로 조회한 KDS/KCS 원문과 적용 조건이 맞는 항목만 부적합으로 판정하고, 적용 조건·계산값이 부족한 항목은 확인 필요로 구분합니다. 기본형의 피복 75mm나 층두께 150mm를 곧바로 법정 기준값으로 사용하지 않습니다.

| 검토 항목 | 오류형 도면에서 읽어야 할 값 | 예상 판단과 필요한 근거 |
| --- | --- | --- |
| 피복 | 20mm, 전 면 동일 표기 | 노출·타설 조건과 최외측 철근을 확인하고 해당 피복 규정과 대조. 조건이 부족하면 확인 필요 |
| 뒤채움재 | 유기질토·건설폐기물 혼합토 | 실제 적용 시방의 허용 재료·유해물 제한과 대조. 확인한 원문이 배제하면 부적합 |
| 다짐 층두께 | 다짐 후 400mm | 원문의 층두께 정의·적용 공종을 확인해 대조. 느슨한 포설 두께와 혼동 금지 |
| 다짐도 | 90% | 기준 밀도·시험방법·시공부위가 부족하면 확인 필요. 모든 공종에 동일한 다짐도 기준을 가정하지 않음 |
| 겹이음 | V1A/V1B, EL.+0.600~0.800의 200mm 겹침 | 실제 형상에서 겹침을 확인. 계산 이음길이·응력·이음 등급과 비교해야 하므로 200mm만으로 적합 확정 금지 |
| 이음 위치 | 벽체 기부 최대인장 예상구간, 동일 단면 전수 이음 | 설계 지정·이음 분산 규정 및 구조계산 확인 필요. “최대인장 예상”을 계산으로 확정한 사실처럼 쓰지 않음 |
| H1 단중 | D13, 표 1.200kg/m | 공식 원문에서 0.995kg/m를 판독하면 단중 불일치. 아래 수량표 차이를 제시 |
| 옹벽 안정성 | 토압·수압·활동·전도·지지력 계산 미제공 | 도면만으로 적합 판정 불가, 구조·지반 검토 필요 |

실제 답변의 기준 열에는 **조회한 기준 코드·개정연도·조항·원문 조건·출처**를 넣어야 합니다. 이 문서는 특정 조항번호를 정답으로 미리 지정하지 않습니다. 조회 실패 시 해당 열을 “원문 미확보”로 표시하고 기준 검증을 완료했다고 말하지 않아야 합니다.

| H1 단중 검토 | 독립 산출 | 오류형 수량표 | 차이·판정 |
| --- | ---: | ---: | --- |
| 본수·가공길이 | 32본×5.9473m=190.3136m | 동일 | 길이·본수 일치 |
| 단중 | 0.995kg/m | 1.200kg/m | 표가 0.205kg/m 큼 |
| 중량 | 189.362kg | 228.376kg | 표시된 표 중량 대비 약 39.014kg 과다 |

피복을 줄이고 V1을 나눴으므로 오류형 철근량은 기본형과 다릅니다. 오류형 총 철근 독립 산출값은 **1,139.282kg**이며 기본형 1,086.333kg를 그대로 재사용하면 안 됩니다. 결과 뒤에는 사용자가 바꾸고 싶은 판단·표시 방법을 묻습니다.

### 3. 기성도면 작성

기성 표시가 없는 기본형을 다시 열고 다음과 같이 요청합니다.

> 이 옹벽은 기초콘크리트 타설까지 완료됐어. 터파기, 린콘크리트, 기초콘크리트, 기초 철근 B1/B2와 전장 선조립한 벽체 수직근 V1을 기성 범위에 포함해 표시해줘. 면적이 있는 부분은 해칭하고 철근은 강조선으로 표시해줘. 기성 물량과 제외 공종을 채팅 표로 보여주고 원본과 다른 파일명으로 저장해줘.

이 시험의 기성 비교값은 터파기 149.100m³, 린 1.560m³, 기초 콘크리트 5.760m³, B1/B2/V1 철근 합계 **900.473kg**입니다. 벽체 콘크리트·H1 수평근·일반 되메움·구조물 뒤채움은 후속 공정으로 제외합니다. 지수재는 기초 양생 후 벽체 타설 전에 설치한다는 조건이므로 이 단계에서는 제외합니다.

**예상 답변 예시**

> 기초 타설 완료 조건과 벽체 수직근 전장 선조립 조건으로 기성 범위를 정했습니다. 터파기·린·기초 단면에는 별도 기성 레이어의 해칭을, V1에는 강조선을 표시했습니다. 면적이 없는 철근을 해칭 면적으로 환산하지 않았습니다.

| 이번 기성 포함 | 수량 | 표시·근거 |
| --- | ---: | --- |
| 터파기 | 149.100m³ | 굴착 단면 해칭, 체적은 단면×연장 6m |
| 린콘크리트 | 1.560m³ | 린 단면 해칭 |
| 기초 콘크리트 | 5.760m³ | 기초 단면 해칭 |
| B1·B2 기초 철근 | 529.639kg | 기호별 가공 길이·본수 대조 |
| V1 벽체 수직근 | 370.834kg | 기초 정착 및 전장 선조립 조건, 2면 대표 강조선 |
| 철근 기성 합계 | 900.473kg | B1+B2+V1, 강조선과 실제 철근의 중복 합산 없음 |

> 벽체 콘크리트 5.400m³, H1 185.860kg, 일반 되메움 4.980m³, 구조물 뒤채움 73.800m³, 지수재 6m는 이번 기성에서 제외했습니다. 지수재는 기초 양생 후 설치 조건입니다. 저장 성공 시 실제 파일명·저장 결과를 안내하고, 실패하면 미저장 상태와 이미 적용한 표시를 알려야 합니다. 원하는 기성 범위와 표시 방법에 맞는지 확인해 주세요.

`retaining-wall-3m-foundation-progress.dwg`에는 터파기·린·기초 해칭과 벽체 수직근 강조선이 미리 들어 있습니다. 이는 표시 결과를 비교하는 예시이며 LLM이 이번에 작성한 실행 결과는 아닙니다.

### 1. 통로박스 물량 산출·검증

`box-culvert-2x3-normal-corrected.dwg`를 열고 입력합니다.

> 이 통로박스의 콘크리트, 린콘크리트, 터파기, 되메움·뒤채움, 지수재와 철근 물량을 산출해줘. 터파기는 횡단면에 연장만 곱하지 말고 종방향 양단 사면을 포함해줘. 철근은 기호별 실제 가공 길이·본수·직경과 독립 공식 단중 원문으로 검증하고 수량표 대조 결과를 채팅 표로 보여줘. 도면은 변경하지 말아줘.

**예상 답변 예시**

> 내공 2×3m, 외곽 2.6×3.6m, 구조물 연장 6m를 확인했습니다. 개구부 공극은 콘크리트에서 제외했고, 터파기는 저면 3.8×7.2m·깊이 4.7m·종횡 1V:1H 확장체로 계산했습니다.

| 항목 | 예상 수량 | 근거 |
| --- | ---: | --- |
| 기초 콘크리트 | 4.680m³ | 2.6×0.3×6 |
| 벽체 콘크리트 | 10.800m³ | 양측 0.3×3×6 |
| 상부슬래브 콘크리트 | 4.680m³ | 2.6×0.3×6 |
| 콘크리트 합계 | 20.160m³ | 외곽에서 내공 제외 |
| 린콘크리트 | 1.736m³ | 2.8×6.2×0.1 |
| 터파기 | 510.013m³ | 종횡 양방향 사면 확장체 |
| 되메움·뒤채움 합계 | 452.117m³ | 굴착−콘크리트−린−내공 36m³ |
| 지수재 | 12.000m | 양측 벽체 시공이음 각 6m |
| 철근 합계 | 2,339.964kg | 기호별 6개 행, 반올림 전 합계 |

이 시험의 되메움·뒤채움 합계에는 구조물 주위와 상부 토피의 채움 공간을 포함합니다. 별도의 재료별 구역 수량이나 반출토량으로 바꿔 말하지 않아야 합니다. 굴착은 **4.7×[3.8×7.2+(3.8+7.2)×4.7+(4/3)×4.7²]=510.012666…m³**이며 단면적×6m만으로 계산하면 실패입니다.

| 기호 | 규격 | 본수 | 1본 길이 | 총길이 | 독립 중량 | 수량표 대조 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| B1 | D19 | 62 | 2.4309m | 150.7158m | 339.111kg | 일치 |
| B2 | D16 | 28 | 5.8341m | 163.3548m | 254.833kg | 일치 |
| T1 | D19 | 62 | 2.4309m | 150.7158m | 339.111kg | 일치 |
| T2 | D16 | 28 | 5.8341m | 163.3548m | 254.833kg | 일치 |
| V1 | D16 | 124 | 4.0341m | 500.2284m | 780.356kg | 일치 |
| H1 | D13 | 64 | 5.8373m | 373.5872m | 371.719kg | 일치 |

> 본수는 배근 주기(예: V1 4면×31본, H1 4면×16본)에서 읽었습니다. 대표 원이나 가공선의 개수를 설치 본수로 사용하지 않았습니다. 단중 원문·페이지를 실제로 읽은 경우에만 중량 검증 완료로 표시합니다. 원문을 읽지 못하면 길이·본수 검증과 중량 미검증을 구분합니다. 이 결과가 필요한 방식과 맞나요?

### 2. 통로박스 설계오류 검토

`box-culvert-2x3-noncompliant.dwg`를 열고 입력합니다.

> 이 통로박스의 피복, 뒤채움재와 층두께·다짐도, 뒤채움 경사, 철근 겹이음과 단중, 지수재 설치 시점의 오류를 검토해줘. KDS/KCS를 MCP로 실제 조회해서 기준 코드·개정연도·조항과 도면 근거를 채팅 표로 보여줘. 설계서 지정값과 국가기준값을 구분하고, 도면은 수정하지 말아줘.

**예상 답변 예시**

> 피복 20mm, 유기질토·건설폐기물 혼합 뒤채움재, 다짐 후 400mm·다짐도 90%, V1A/V1B 200mm 전수 겹이음을 확인했습니다. 노출·시험·응력·이음 조건을 실제 원문과 대조하고, 미확인 조건은 확인 필요로 남깁니다.

| 항목 | 도면 증거 | 예상 답변에 필요한 판단 |
| --- | --- | --- |
| 피복·재료·층두께·다짐도 | 20mm·혼합토·400mm·90% | 옹벽 예시와 같이 적용 조건 및 조회한 원문을 제시. 수치만으로 일괄 판정하지 않음 |
| 뒤채움 경사 | 실제 1V:0.5H, 설계 지정 1V:1H | **시험 설계 지정과 불일치**. 1V:1H를 보편적 KDS/KCS 의무값으로 인용하면 안 됨 |
| 겹이음 | 중앙 200mm, 최대인장 구간·동일 단면 전수 이음 표기 | 실제 가공선·겹침을 읽고 계산 이음길이·설계 상세 확인 필요 |
| H1 단중 | D13, 1.200kg/m | 공식 표를 실제 판독해 0.995kg/m와 다르면 단중 불일치 |
| 지수재 설치 시점 | 수팽창 지수재를 기초 타설 전에 선설치 | 제품별 시공 지침과 적용 시방 확인 필요. 기초 양생 후 시공하는 정정 기본형과 다르며 모든 종류의 지수판 설치 규칙으로 일반화 금지 |
| 구조·지반 안전 | 구조계산 미제공 | 최종 적합 판단 불가 |

| H1 검토값 | 독립 산출 | 오류형 수량표 | 차이·판정 |
| --- | ---: | ---: | --- |
| 본수·가공길이 | 64본×5.9473m=380.6272m | 동일 | 길이·본수 일치 |
| 단중 | 0.995kg/m | 1.200kg/m | 표가 0.205kg/m 큼 |
| 중량 | 378.724kg | 456.753kg | 표시된 표 중량 대비 약 78.029kg 과다 |

실제 오류형의 철근 총 독립 산출값은 **2,447.234kg**입니다. 피복·이음 형상이 달라졌으므로 기본형 총량을 그대로 쓰면 안 됩니다. 기준 원문이 없으면 해당 항목은 “원문 미확보·검증 미완료”로 답하고 조항번호를 만들지 않아야 합니다. 끝에는 사용자에게 보완할 판단 규칙을 묻습니다.

### 3. 통로박스 기성도면 작성

기성 표시가 없는 `box-culvert-2x3-normal-corrected.dwg`를 다시 열고 입력합니다.

> 이 통로박스는 기초콘크리트 타설까지 완료됐어. 터파기, 린, 기초콘크리트, B1/B2 기초 철근과 기초에 정착해서 전장 선조립한 벽체 수직근 V1을 기성 범위에 포함해줘. 면은 해칭, 철근은 강조선으로 표시하고 포함·제외 물량을 채팅 표로 보여줘. 원본과 다른 이름으로 저장해줘.

**예상 답변 예시**

> 기초 타설 단계의 터파기·린·기초에 해칭을 표시하고, 선조립한 벽체 수직근을 포함했습니다. 기성 표시선 자체를 철근량에 추가하지 않았습니다.

| 기성 항목 | 이번 수량 | 포함 이유 |
| --- | ---: | --- |
| 터파기 | 510.013m³ | 종횡 양방향 굴착 완료 가정 |
| 린콘크리트 | 1.736m³ | 기초 하부 타설 완료 |
| 기초 콘크리트 | 4.680m³ | 이번 타설분 |
| B1·B2 기초 철근 | 593.944kg | 기초 배근 완료 |
| V1 벽체 수직근 | 780.356kg | 124본 전장 선조립 완료 조건 |
| 철근 기성 합계 | 1,374.300kg | B1+B2+V1 |

> 벽체 콘크리트 10.800m³, 상부슬래브 4.680m³, T1/T2 상부 철근 593.944kg, H1 수평근 371.719kg, 되메움·뒤채움 452.117m³는 후속 공정으로 제외했습니다. 정정 기본형의 지수재 12m도 기초 양생 후 설치하므로 이번 기성에서 제외했습니다. 저장 성공을 확인한 파일명과 기성 범위를 안내하고, 필요한 표시 방법이 맞는지 묻습니다.

`box-culvert-2x3-foundation-progress.dwg`는 표시 비교용입니다. 새 기성 프롬프트는 원본인 정정 기본형에서 시작해야 중복 표시를 피할 수 있습니다.
