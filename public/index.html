VWorld API

키 연결 상태 확인 전

조회한 필지 경계를 실제 크기로 도면에 삽입하고 위치 기준을 보존합니다. 경기도 광주시는 주소만으로 공개 등고선을 자동 조회합니다. 다른 지역은 아래에서 원본을 등록하세요. 공인 측량 경계로 사용할 수 없습니다.

지형 원본 등록

브라우저에서는 GeoJSON 1개 또는 같은 이름의 SHP·DBF·PRJ 3개를 함께 선택하세요. 업로드 합계는 128MiB 이하이며 GeoJSON은 32MiB 이하입니다.

다운로드한 SHP(같은 폴더의 DBF·PRJ 필수) 또는 GeoJSON을 선택합니다. VWorld API 키와 원본 다운로드 권한은 별개이며, 포털 다운로드에는 로그인이 필요할 수 있습니다. 전국 지형 자료가 자동으로 포함되지는 않습니다.

경기도 광주시 주소만 채팅에 입력하면 반경 100m의 필지와 공개 등고선을 자동 조회·등록하고 같은 위치·실척으로 삽입해 DWG로 저장합니다. 표고는 m로 해석하며 수직 기준면은 미확인입니다. 같은 영역의 검증된 원본은 재사용합니다. 다른 지역은 공개 GeoJSON 주소를 채팅에 붙여 넣고 “다운로드해 지형 원본으로 등록하고 도면에 넣어 저장해줘”라고 요청할 수 있습니다. 실제 좌표·표고를 검증한 자료만 등록하며 ZIP·인증 포털은 이 경로에서 지원하지 않습니다.

VWorld 등고선 원본 안내

등록 후 채팅에서 주소 주변 1km² 이하 영역을 조회·삽입·DWG 저장하도록 요청하세요. 필지와 동일한 EPSG:5179 위치 기준·모형 실척 1:1을 적용하고, 원본 표고를 Z 높이로 보존합니다. 표고 기준이 불명확하면 변환하지 않으며 자료 밖의 보간·외삽 지형을 만들지 않습니다.
