# SiteCAD — 자연어로 작업하는 로컬 CAD

SiteCAD는 OpenCADStudio 편집기와 전용 Codex App Server·MCP를 연결하는 macOS·Windows 로컬 브라우저 앱입니다. ChatGPT에 로그인한 뒤 채팅으로 2D 도면과 지원되는 3D 형상을 만들고 수정하거나 물량을 검토하고 DWG로 저장합니다. CAD 파일 처리와 도구 실행은 내 PC에서 이루어지며 AI 요청은 온라인 서비스를 사용합니다.

**[Windows ZIP](https://github.com/seominpapa/SiteCAD/releases/download/v0.14.0/SiteCAD-0.14.0-local-web-Windows.zip)** · **[macOS ZIP](https://github.com/seominpapa/SiteCAD/releases/download/v0.14.0/SiteCAD-0.14.0-local-web-macOS.zip)** · [릴리스와 SHA-256](https://github.com/seominpapa/SiteCAD/releases/latest)

## 설치·실행

1. 릴리스의 운영체제에 맞는 `SiteCAD-0.14.0-local-web-Windows.zip` 또는 `SiteCAD-0.14.0-local-web-macOS.zip`을 다운로드하고 쓰기 가능한 폴더에 압축을 풉니다. GitHub의 자동 생성 `Source code.zip`보다 위 설치 ZIP을 권장합니다.
2. Windows는 `Start SiteCAD.cmd`, macOS는 `Start SiteCAD.command`를 더블클릭합니다. 최초 실행은 전용 Node.js 24.22.1, 잠금 파일의 운영 의존성, Codex 0.163.0 및 내부 MCP·REA 패키지를 자동으로 준비합니다. Git·Homebrew·전역 Node/Codex 설치는 필요하지 않습니다.
3. 브라우저가 열리면 **ChatGPT로 계속**으로 로그인하고 계정 사용 권한을 연결합니다. 계정에서 허용되는 모델과 플랜 사용 한도가 적용됩니다.
4. 채팅으로 도면을 작성하고 **DWG 저장** 또는 응답의 다운로드 링크로 저장합니다. 종료 전 저장한 뒤 **실행기 종료**를 누릅니다. 브라우저 탭을 닫는 것만으로 실행기가 종료되지는 않습니다.

macOS가 실행을 차단하면 파일 출처를 확인하고 **시스템 설정 → 개인정보 보호 및 보안**에서 해당 실행을 허용합니다. 최초 실행·키체인·계정 권한 승인은 사용자가 진행합니다. 자동 우회하지 않습니다. 서명·공증된 설치 앱이 아닌 로컬 실행 스크립트입니다.

최초 설치와 로그인에는 인터넷이 필요하며 이후 실행은 설치된 의존성을 재사용합니다. 설치 실패 시 같은 실행 파일을 다시 열어 복구합니다. 실행 중 터미널 창은 유지합니다. Apple Silicon에서 실제 설치·로그인·DWG 검증을 수행했습니다. Windows 10/11 64비트 x64·ARM64 설치 경로를 제공합니다. Linux 자동 설치기는 제공하지 않습니다. Windows ARM64와 Intel Mac 실기기는 미검증입니다.

Windows에서는 ZIP 안에서 실행하지 말고 **모두 압축 풀기** 후 실행하세요. 관리자 권한·Git·전역 Node 설치는 필요하지 않습니다. PowerShell은 해당 실행에만 실행 정책을 적용하며 시스템 설정을 바꾸지 않습니다. 회사의 실행 제한·보안 제품 정책이나 로그인 승인은 자동으로 우회하지 않습니다.

## 할 수 있는 작업

- DWG 열기, 기본 2D 작도, 객체 이동·삭제, 치수·한글 주석 작성, 레이어별 객체 조회와 측정
- 엔진의 명령 검색·실행 및 후속 입력을 AI가 판단해 진행
- 기존 범용 연결로 레코드 속성·레이어·선종류·문자/치수 스타일 수정, 블록 정의·삭제, 배치 생성·전환·페이지 설정과 제한된 시스템 변수 조정
- 기존 범용 연결로 3D 기본 입체, 돌출·회전·스윕·로프트, 합집합·차집합·교집합, 3D 변환·선·면·메쉬와 표준 방향·음영 보기 명령 실행
- 레이어별 객체 수·길이·폐합 면적을 물량 표로 표시
- 웹검색·문서 fetch, 공개 자료 다운로드와 계산을 설계 참고에 활용
- VWorld 주소·필지 조회, 좌표계 변환과 실척 삽입
- 등록된 SHP/GeoJSON 등고선·표고를 필지와 같은 기준으로 삽입
- 주소만으로 필지·공개 등고선을 확보하는 자동 경로: **현재 경기도 광주시 제공 범위**
- 명시적으로 등록·신뢰한 외부 MCP 연결. REA는 설치된 사전 설정으로 제공
- 도면 변경 감지, 저장 감사와 누락 검사, 검증된 DWG의 보관·다운로드

예: “6000×4000mm 사각형을 그리고 한글 주석과 가로 치수를 넣어 DWG로 저장해줘.”

2D·3D 범용 연결은 기존 `cad_discover`·`cad_query`·`cad_control`을 사용하며 기능별 새 도구를 만들지 않습니다. 설치된 엔진의 `record_schema`와 실제 `records`를 조회한 뒤 `set_properties`로 현재 값과 일치할 때만 수정합니다. 엔진에 존재하는 명령과 현재 웹 빌드에서 실행 가능한 명령을 구분하고, 한글 이름·후속 입력·명령 완료 상태를 처리합니다. `STYLE`·`DIMSTYLE`은 대화상자를 열지 않는 `LIST`·`NEW` 형식만 허용하며 지원되는 설정 변경은 시스템 변수와 레코드 속성을 사용합니다.

3D도 같은 명령 검색·실행·후속 입력 경로를 사용합니다. 예: “6000×4000×3000mm 박스를 만들고 원기둥을 빼서 구멍을 낸 뒤 체적을 확인하고, 등각 음영 보기로 DWG 저장해줘.” `Solid`는 2D 채움 면이며 `entities_create`에 `Solid3D`를 넣지 않습니다. 입체는 `BOX`·`EXTRUDE` 등 실제 지원 명령으로 생성합니다. 높이가 변하는 폴리선은 Z를 무시하는 `LwPolyline` 대신 `3DPOLY`를 사용합니다. 3D 회전·대칭·정렬은 해당 3D 명령을 사용하고, `VIEW SWISO` 같은 정해진 보기와 `VISUALSTYLES`의 7개 표시 모드만 실행합니다. `3DORBIT` 마우스 회전 모드와 미구현 `VPOINT`는 LLM에 열지 않습니다. `SOLIDEDIT`는 현재 엔진의 셸 편집 경로이며 AutoCAD의 모든 솔리드 편집 옵션을 뜻하지 않습니다. 체적·표면적 측정값은 각각 도면 단위의 세제곱·제곱이며, 값이 없으면 미지원으로 보고합니다. 프로파일·불리언 작업은 원본을 지울 수 있고 형상에 따라 거부될 수 있으므로 결과 객체·측정값을 확인합니다. 레이어별 물량 표는 기존 2D 집계이며 3D 체적 표로 자동 확장되지 않습니다.

블록은 실제 조회한 객체를 대상으로 정의하며 강제 삭제는 해당 블록을 참조하는 삽입 객체도 지울 수 있습니다. 배치 방향을 변경할 때는 용지 이름과 방향을 함께 지정합니다. 배치·페이지 설정은 기존 엔진 기능을 이용하지만 **웹 빌드의 `plot`·`wblock` 파일 출력은 native-only로 지원하지 않습니다. 페이지 설정 성공이 PDF 출력 성공을 뜻하지 않습니다.** 도면 식별자·수정 상태·좌표 단위·선택 변경 검사와 지리 기준 보호, 전용 DWG 저장 검증은 유지합니다. 범용 연결 확장은 0.14.0 설치 ZIP에 포함됩니다.

VWorld 키는 앱의 설계 참고 연결 설정에서 사용자가 등록합니다. 저장소와 배포 파일에는 키가 없습니다. SHP는 같은 이름의 SHP·DBF·PRJ를 함께 선택합니다. 외부 MCP 호출은 서버·도구·인수를 표시하고 1회 승인 또는 거절을 받습니다.

## 채팅·MCP·스킬 — 0.14.0

우측 **채팅 접기**로 도면을 넓게 사용하고 **채팅 열기**로 복귀합니다. **새 채팅**과 기록 선택으로 대화를 나눕니다. 대화별 Codex 스레드를 따로 저장하고 재실행 시 복원하며, 대화 본문은 SiteCAD 전용 `chat-sessions/`에 보관합니다. 채팅을 바꿔도 현재 CAD 도면은 유지됩니다. 이전 대화의 객체 핸들이 현재 도면과 일치한다고 가정하지 않습니다. 기록 화면 복원은 현재 텍스트 기준이며 물량 표·출처 카드·다운로드 링크는 다시 구성하지 않습니다. 채팅은 최대 100개, 채팅당 메시지 500개까지 보관합니다.

- “REA MCP를 연결해줘”: 번들 REA의 실행 설정을 검토하고 승인 후 연결합니다.
- GitHub MCP URL과 “설치해줘”: 공개 저장소·고정 커밋과 npm 배포 원본·버전·SHA-512를 확인한 뒤 정확한 실행 파일과 인수를 승인받습니다. 현재 자동 설치 대상은 같은 GitHub 저장소를 표시하는 **npm 배포 Node MCP**입니다. 소스 빌드·Python·임의 셸 설치 명령은 지원하지 않으며 필요한 별도 실행 환경은 수동 설정합니다. 설치 스크립트는 실행하지 않습니다.
- HTTPS MCP 주소와 “연결해줘”: 승인 후 SiteCAD 전용 설정에 등록합니다. 인증값은 채팅 대신 기존 MCP 설정 화면에 입력합니다.
- “지금까지 작업을 `site-check` 스킬로 만들어줘”: 현재 대화의 작업을 재사용 가능한 지침으로 저장합니다. **/ 스킬** 목록에서 선택하거나 `/site-check 요청 내용`으로 실행합니다. 서버가 설치된 스킬 경로를 확인해 Codex 네이티브 `skill` 입력으로 전달합니다. 기존 스킬 수정은 원문 해시 확인과 덮어쓰기 승인이 필요합니다.

`skill-creator`·`skill-finder`·`skill-installer`를 기본 제공합니다. SiteCAD 관리 도구에 맞춘 번들 지침이며 외부 마켓플레이스 패키지를 설치한 것으로 표시하지 않습니다. 기본 스킬은 첫 실행에 `codex-home/skills/`에 준비하며 사용자 스킬을 덮어쓰지 않습니다. `skill-finder`는 설치된 스킬을 검색하고, 외부 후보 조사는 웹검색으로 진행합니다. `skill-installer`는 검토한 지침을 SiteCAD 스킬로 저장하며 임의 저장소의 스크립트를 실행하지 않습니다.

설치 승인은 프로그램의 지속적인 등록·실행에 대한 동의입니다. 외부 MCP는 운영체제 사용자 권한으로 실행되며 Codex의 읽기 전용 샌드박스와 별개입니다. 설치·등록은 현재 채팅 작업 종료 후 적용하고 실제 MCP 도구 목록을 확인한 경우만 연결 완료로 표시합니다. 실패하면 새 등록을 되돌리고 기존 설정을 보존합니다. 추가한 서버는 다음 메시지부터 사용할 수 있으며 이후 외부 도구 호출에는 기존 1회 승인이 계속 적용됩니다. 이 기능은 0.14.0 릴리스 ZIP에 포함됩니다.

2026-10-24 macOS 실제 브라우저 검증에서는 ChatGPT 로그인 후 내부 CAD 조회, 대화 기록을 읽은 스킬 생성, `/qa-drawing-check` 실행, 서로 다른 Codex 스레드의 맥락 분리와 재연결 후 원래 대화 복원을 확인했습니다. 채팅에서 번들 REA를 승인·등록한 뒤 Codex에서 도구 207개를 확인하고 `binary_session {}`을 한 번 실행해 REA 6.7.0의 실제 응답을 받았습니다. 채팅 완료 시 외부 MCP 연결 표시도 갱신합니다. 이 검증은 도면을 수정·저장하지 않는 조회 범위이며 새로운 MCP 패키지 다운로드, Windows 실기, DWG·AutoCAD 재검증과 릴리스 배포를 포함하지 않습니다.

3D 측정의 `mesh.volume`·`mesh.surface_area`는 삼각형으로 나눈 형상의 근사값이며 DWG를 다시 열면 분할 정밀도에 따라 달라질 수 있습니다. 정확한 커널 질량 특성으로 표시하지 않습니다. 현재 엔진은 재개방한 일부 ACIS 입체의 경계를 0으로 반환하므로 이 값은 위치·정렬 검증에 사용할 수 없습니다. 로컬 검증에서는 저장한 동일 DWG를 AutoCAD에서 열어 실제 솔리드 체적·좌표와 `AUDIT`를 별도로 확인했습니다.

전국 지형 자동 확보, 로그인 포털 자료의 자동 다운로드, DEM 래스터·지표면 메쉬, 스캔/지도 이미지 형상 추출, 구조 설계 적합성 판단, 별도 파라메트릭 3D 설계·조립 이력 시스템 및 다중 사용자는 현재 범위에 포함하지 않습니다. 지원 명령 연결이 모든 3D 형상의 호환성을 보증하지는 않습니다. 필지·지형의 출처·좌표계·표고 기준·정확도를 확인해야 하며 공인 측량 경계나 설계 승인을 대신하지 않습니다.

## 데이터와 보안

- 사용자 데이터: macOS `~/Library/Application Support/SiteCAD Web/`, Windows `%LOCALAPPDATA%\SiteCAD Web\`
- 도면: 위 폴더의 `Drawings/`. 위치 기준이 있는 DWG는 함께 저장되는 `.sitecad.json` 보조 파일도 보관합니다.
- 앱 전용 `codex-home/`·`workspace/`를 사용하며 기존 Codex 앱·CLI의 설정과 로그인을 수정하지 않습니다.
- 추가 MCP 패키지는 `managed-mcp/`, 스킬은 `codex-home/skills/`, 채팅·Codex 대화 기록은 SiteCAD 사용자 폴더에만 보관합니다. 사용자 스킬·추가 MCP·대화·인증 정보는 배포 ZIP에 포함하지 않습니다.
- 인증 정보는 macOS 키체인 또는 Windows 자격 증명 관리자에 보관한 키로 암호화하며 평문 대체 저장을 하지 않습니다.
- Node 런타임·의존성은 설치 폴더의 `.runtime/`, `node_modules/`, `runtime/`에 준비됩니다. 이 웹앱 경로는 Electron을 설치하거나 실행하지 않습니다.
- 로컬 서버는 loopback에만 연결하며 호스트·출처·브라우저 연결 권한을 검사합니다. 하나의 브라우저 탭만 도면 작업을 소유합니다.
- 전체 DWG 파일을 모델에 업로드하지 않지만 채팅 내용·작업에 필요한 객체 문맥과 도구 결과는 AI 요청에 포함됩니다.

회사에서 터미널·자식 프로세스·네트워크 실행을 차단하는 경우 담당자의 허용이 필요합니다. 앱은 해당 정책을 우회하지 않습니다. 저장을 요청하지 않은 편집은 자동으로 디스크에 보존되지 않으므로 중요한 업무 도면은 복사본으로 작업하세요.

## 소스에서 실행·검사·패키징

이 저장소의 루트에서 `Start SiteCAD.command`를 실행해도 같은 준비 절차가 동작합니다. 편집기 스냅샷과 예제 도면은 저장소에 포함돼 있습니다.

```sh
git clone https://github.com/seominpapa/SiteCAD.git
cd SiteCAD
# Windows: Start SiteCAD.cmd / macOS: Start SiteCAD.command 더블클릭
# 개발용 Node를 사용하는 경우:
npm ci
node scripts/install-codex.mjs
npm run local-web
npm test
npm run local-web:build
npm run local-web:build:windows
```

`npm start`는 초기 구조화 계획기 시제품입니다. 전체 MCP 기능에는 원클릭 실행기 또는 `npm run local-web`을 사용합니다. 기존 Electron 경로는 `npm run desktop`, 개발 앱 빌드는 `npm run desktop:build`이며 권장 설치물은 로컬 브라우저 ZIP입니다.

배포 ZIP은 명시된 소스·잠금 파일·편집기 스냅샷·라이선스·예제만 포함합니다. 사용자 인증·API 키·도면·실행 캐시·설치된 의존성은 제외합니다. Node와 Codex 다운로드는 고정 SHA-256으로 검증합니다. 릴리스의 `SHA256SUMS.txt`로 내려받은 파일도 확인할 수 있습니다.
