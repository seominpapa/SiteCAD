# SiteCAD 기성도면 표시

"이 구간 기성 표시", "기초콘크리트 타설분 청구", "완료한 공정 표시해줘"처럼 슬래시 없는 요청에도 적용한다. 단순 공정 설명/가정 질문은 실제 표시 요청이 아니므로 도면을 변경하지 않는다. `sitecad_skills`는 권한을 추가하지 않는다.

## 회차와 시공 범위

1. `cad_context`와 `cad_query`로 현재 문서·선택·시공 구간·부재·기존 기성 표시를 확인한다. 사용자가 지정한 회차·구간·완료 공정을 우선하며 이전 채팅의 핸들을 재사용하지 않는다. 불명확한 완료 범위를 전체 도면으로 확대하지 않는다.
2. 단위·축척이 불명확해도 원시 도면 좌표로 이미 지정된 범위의 표시가 가능한지 확인한다. 물리적 수량 환산은 별도로 확인하며 도면 단위·원본 축척을 변경하지 않는다. `cad_discover`로 실제 지원 생성 형식·해칭 패턴을 확인한다.
3. 기초콘크리트 타설 완료를 표시하라는 요청이면 해당 시공 구간의 선행 터파기·린콘크리트(버림)·기초 배근과 기초 콘크리트를 후보로 조회한다. 이것은 사용자가 승인한 공정 묶음이며, 선행 작업의 전 도면 완료를 추정하는 규칙이 아니다. 린콘크리트는 철근콘크리트 기초와 다른 항목으로 둔다.
4. 기초 타설 시 설치된 기둥/벽체 수직철근·세움철근·기초 정착부와 실제 배근된 이음/스타터를 포함한다. 가공상세와 시공 단계 근거에 따라 실제 설치한 한 본의 전체 가공길이를 세되 기초 철근과 정착부를 중복 계산하지 않는다. 기초 타설만으로 벽체 수평근·상부슬래브근·상부 콘크리트·뒷채움을 완료 처리하지 않는다. 후속 세움철근이 아직 미설치이거나 분할 설치되었으면 실제 설치분만 반영한다.
5. 선행 공정 포함은 기성 청구 자격·단가·계약 지급조건의 자동 승인과 다르다. 회차별 기청구량·금회·누계를 나누고 이미 청구된 동일 구역·철근 기호를 다시 더하지 않는다. 과거 기성 근거가 없으면 "중복 없음"을 보증하지 않고 첫 회차 가정 등을 표시한다.

## 원본을 보존하는 표시

6. 원본 형상과 레이어를 수정하지 않고 `SITECAD_PROGRESS_<회차>` 같은 별도 레이어에 표시한다. 같은 회차·구간 표시가 있으면 실제 객체를 조회하여 재사용/변경 여부를 확인하고 중복 해칭을 만들지 않는다. 해칭 자체의 면적을 두 번째 물량으로 더하지 않는다.
7. 토공 횡단면 등의 명확한 폐합 영역은 빗금 해칭으로 표시한다. 구멍·자가교차·복수 영역을 지원하지 않으면 임의의 외접 사각형을 해칭하지 말고 해당 경계만 외곽선으로 표시하고 제한을 밝힌다. 열린 경계를 임의로 연결해 청구 면적을 만들지 않는다.
8. 철근·지수재·개별 객체 등 면적이 없는 대상에는 색상선·외곽선·주석/번호로 표시하고 대응 원본 핸들·기호를 결과에 남긴다. 원본 철근 색상/길이/수량을 변경하지 않는다. 회차·구간·공정·범례를 표시한다.
9. 매 변경 전에 실제 도면 상태를 확인하고 `cad_control`의 기존 리비전·선택·진행 중 명령·지리정보 보호를 유지한다. 실패 후 일부 객체가 만들어졌을 수 있으므로 조회 후 재시도한다. 완료 시 실제 생성 객체·레이어·범위 밖 침범·중복을 확인한다. 저장 요청이 있으면 `cad_save`의 실제 결과를 확인하고 기존 도면을 자동 덮어쓰지 않는다.

물량도 요청했으면 `quantity-review`를 읽어 독립 산출한다. 채팅창의 GFM 표는 `공정·부재/기호 | 포함 근거·시공 구간 | 설계 수량 | 기청구 | 금회 | 누계 | 단위 | 표시 위치·미확인`으로 작성한다. 시험 가정·시공 확인·계약 승인을 구분하며 읽지 못한 값은 0이 아닌 미확인으로 남긴다.
